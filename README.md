# Bobby's Fabric Mods

Two client-side Minecraft mods I built from scratch on the Fabric toolchain, for **Minecraft 1.20.1** (requires Fabric Loader ≥ 0.15.0 and Fabric API).

## Mods

### Block ID Copier (v1.0.0)
Press **Shift + middle click** to copy the full block ID of whatever you're looking at — namespace and block states included — straight to your system clipboard, with a live readout in the top-right corner of the screen. Built to make large WorldEdit builds less painful.

- Download: `Block ID Copier-1.0.0-fabric-1.20.1.jar`

### Bobby's Tab Folders (v1.0.3)
Adds customizable folders to the creative inventory: group creative tabs by mod, or any way you like, and switch between folders from a sidebar. For anyone whose creative inventory has become unscrollable.

- Download: `tabfolders-1.0.3.jar`

## Installation

1. Install [Fabric Loader](https://fabricmc.net/use/installer/) and [Fabric API](https://modrinth.com/mod/fabric-api)
2. Drop the .jar files into your `.minecraft/mods` folder
3. Launch the game

## Requirements

| Component | Version |
|-----------|---------|
| Minecraft | 1.20.1 |
| Fabric Loader | ≥ 0.15.0 |
| Java | ≥ 17 |
